Выполнение:
    1) docker compose up -d 
    (создался контейнер из файла compose.yaml - compose.yaml имеет больший приоритет), так как
    The default path for a Compose file is compose.yaml (preferred) or compose.yml that is placed in the working directory. 
    Compose also supports docker-compose.yaml and docker-compose.yml for backwards compatibility of earlier versions.
     If both files exist, Compose prefers the canonical compose.yaml

    2) Добавляем в compose.yaml
        include:
            - docker-compose.yaml

        Выполняем: docker compose up -d 
    
    3) Пуш в локальный регистри 
        - docker run -d -p 5000:5000 --restart=always --name registry registry:3 - создание локального регистри
        - docker tag custom-nginx:1.0.0 localhost:5000/custom-nginx:latest - меняем тег у нашего образа на latest
        - docker push localhost:5000/custom-nginx:latest - пуш образа в локаальный registry
        - docker images localhost:5000/custom-nginx - проверка образа в локальном регистри
