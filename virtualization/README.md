Задача 3
1) Подходит Microsoft Hyper-V. Этот продукт хорошо интегрируется с Windows Server и Active Directory, 
обеспечивая удобное управление инфраструктурой через консоль PowerShell или GUI. Hyper-V поддерживает продвинутые функции для балансировки нагрузки (напри
мер, Network Load Balancing), встроенную репликацию данных и простой механизм создания резервных копий через встроенные средства. 
Решение доступно бесплатно вместе с лицензиями Windows Server Datacenter Edition, при этом обладает всеми необходимыми возможностями для эффективного управления средой виртуализации.

2) Лучшим выбором станет Proxmox VE (Proxmox Virtual Environment).
Proxmox основан на Debian и сочетает в себе лучшие стороны KVM (для полноценной виртуализации) и LXC (контейнеризация). 
Он бесплатен, обладает открытым исходным кодом и активно поддерживается сообществом разработчиков.
Proxmox поддерживает широкие возможности мониторинга, автоматического резервного копирования, Live Migration и отлично справляется с нагрузкой даже небольших кластеров.
Благодаря поддержке KVM, возможна эффективная работа как с Linux, так и с Windows VM.

3) Рекомендуется VirtualBox, разработанный Oracle. 
VirtualBox широко распространён среди разработчиков и тестировщиков благодаря своей бесплатности и хорошей интеграции с разными версиями Windows-хостов. 
Хотя изначально ориентированный больше на настольные компьютеры, VirtualBox вполне способен справляться с малыми и средними нагрузками виртуализации, а также поддерживать разнообразные гостевые операционные системы, включая разные версии Windows и Linux.
Он доступен для загрузки и использования абсолютно бесплатно.

4) Оптимальным вариантом здесь будет KVM (Kernel-based Virtual Machine). 
KVM представляет собой технологию виртуализации, встроенную непосредственно в ядро Linux.
Эта технология свободно доступна и идеально подходит для запуска множества виртуальных машин с различными дистрибутивами Linux (Ubuntu, CentOS, Fedora и др.).
К преимуществам KVM относятся высокое быстродействие, низкие затраты ресурсов и отличная интеграция с современными средствами автоматизации, такими как Ansible или Terraform, что облегчает тестирование и разработку.
